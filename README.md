## Description

Mimisbrunnr is an application that works as a media storage manager and streamer. It allows to easily store, consume and share 
content within a local network.
It is named after the mythical well of Mímir in Norse Mythology, whose water, according to the Prose Edda, holds knowledge and wisdom.
